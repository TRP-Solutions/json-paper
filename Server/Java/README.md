# json-paper Java library

This module builds the JSON drawing document consumed by the json-paper
firmware. It requires Java 17.

## Use from another Gradle project

Build and publish the library to your local Maven repository:

```shell
./gradlew publishToMavenLocal
```

Then add it to your application:

```groovy
repositories {
    mavenLocal()
    mavenCentral()
}

dependencies {
    implementation 'solutions.trp:json-paper:1.0.0-SNAPSHOT'
}
```

## Build a display

```java
import solutions.trp.jsonpaper.Color;
import solutions.trp.jsonpaper.Display;
import solutions.trp.jsonpaper.DisplayDocument;
import solutions.trp.jsonpaper.FillMode;
import solutions.trp.jsonpaper.Width;

Display display = new Display()
    .clear(Color.WHITE)
    .circle(160, 80, 30, Color.RED, Width.W1, FillMode.FULL)
    .text(10, 100, "Hello World")
    .pieSlice(650, 100, 70, 270, 90, Color.RED);

DisplayDocument response = display.document();
String json = display.toJson();
String prettyJson = display.toPrettyJson();
```

`DisplayDocument` is immutable and can be returned directly from a Spring Boot
controller. Spring's configured Jackson instance will serialize it:

```java
@GetMapping(produces = MediaType.APPLICATION_JSON_VALUE)
public DisplayDocument display() {
    return new Display()
        .clear(Color.WHITE)
        .text(10, 10, "Generated by Spring Boot")
        .document();
}
```

The library itself does not depend on Spring Boot.

## PHP dashboard sample

`DashboardSample.create(...)` is the Java equivalent of
`Server/PHP/sample/index.php`. Give it the logo path and return the resulting
document from your controller:

```java
@GetMapping(produces = MediaType.APPLICATION_JSON_VALUE)
public DisplayDocument dashboard() throws IOException {
    return DashboardSample.create(Path.of("/path/to/Media/logo.svg"));
}
```

It also accepts a `BufferedImage` when the logo is loaded from a classpath
resource or another source.

## Images and SVG

Raster images can be supplied as a `BufferedImage` or loaded from a path. SVG
files are rendered through Apache Batik:

```java
Display display = new Display()
    .image(10, 150, Path.of("Media/logo.svg"))
    .image(
        10,
        10,
        Path.of("icon.svg"),
        100,
        50,
        Color.TRANSPARENT
    );
```

Opaque pixels are mapped to the nearest supported color: black, white, yellow,
or red. Pixels with alpha below 50% are encoded as transparent.
